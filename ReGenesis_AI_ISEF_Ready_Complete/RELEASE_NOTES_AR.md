# ملاحظات إصدار REGENESIS AI — Release Candidate

## تغييرات هذه النسخة

- استبدال تسجيل الدخول التجريبي OTP بتسجيل/دخول حقيقيين عبر API وJWT، مع إرسال Bearer token للعمليات المحمية.
- حماية نشر الإعلانات ورفع الصور والمساعد الذكي والبحث على الإنترنت بتسجيل الدخول.
- عدم اعتبار المنشآت متحققة تلقائياً؛ أضيف مسار تحقق لمسؤول النظام وسكربت ترقية مسؤول.
- إخفاء إعلانات ومنشآت الحسابات غير المتحققة في بيئة production.
- إزالة البيانات التجريبية من التشغيل الافتراضي، مع إبقاء SEED_DEMO_DATA خياراً صريحاً لبيئة العرض.
- إضافة استيراد CSV للمنشآت مع حفظ اسم المصدر والرابط والتاريخ في وصف السجل، وإبقاء كل السجلات المستوردة غير متحققة.
- إضافة بحث ويب اختياري عبر Tavily أو Brave، وإرجاع روابط المصادر.
- إضافة استعلام مباشر إلى Climate TRACE API v7 لسجلات الأصول الصناعية والانبعاثات، مع توضيح أنها ليست بيانات مشتري/مورد أو بيانات اتصال.
- إضافة Docker Compose profile لتشغيل Ollama محلياً داخل شبكة الخادم دون نشر منفذه للعامة.
- تعديل أوامر التوريد لتبقى Pending؛ لا يتم تسجيل دفع مكتمل أو شحنة موزونة/مشحونة دون تكامل فعلي.
- إضافة مسار قبول/رفض/عرض مقابل لطلبات الشراء، والتحقق من ملكية الإعلان والكمية وصلاحية الطرفين.
- إزالة مؤشرات سوق/ROI/ESG مختلقة أو عرضها كقيم غير متاحة لحين وجود بيانات موثقة.
- إضافة اختبارات أمان وتدفق السوق.

## نتيجة التحقق المحلي

- Backend tests: 8 passed.
- Python compile check: passed.
- Inline JavaScript syntax check with Node.js: passed.
- API smoke tests: health, registration, login/session, protected advisor routes passed.
- Docker Compose validation was not run because Docker CLI was not available in the build environment.

## ما لا يزال مطلوباً قبل الإنتاج التجاري

- مزود بحث عام ومفتاح API فعلي.
- نشر Ollama أو مزود استدلال على خادم عام مناسب.
- حساب استضافة، نطاق، HTTPS، PostgreSQL دائم، مراقبة ونسخ احتياطية.
- تحقق فعلي من المصانع ومستنداتها، سياسة خصوصية وشروط استخدام، مراجعة قانونية.
- بوابة دفع/ضمان مرخصة إذا كانت المدفوعات ستتم داخل المنصة.
- بيانات تشغيلية حقيقية وعوامل انبعاث موثقة ومراجعة فنية مستقلة.
