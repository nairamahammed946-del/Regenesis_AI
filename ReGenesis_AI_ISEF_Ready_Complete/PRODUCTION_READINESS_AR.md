# خطة تجهيز REGENESIS AI للسوق والإنترنت

## الموجود في نسخة الكود الحالية

- تطبيق FastAPI وواجهات API موثقة.
- قاعدة بيانات SQLAlchemy تدعم SQLite محلياً وPostgreSQL عند ضبط الاتصال.
- تسجيل ودخول بحماية JWT وتجزئة كلمات المرور.
- ملفات المصانع وعروض/طلبات المخلفات ومحرك مطابقة تفسيري.
- مساعد REGENESIS AI متصل بسجلات المنصة، وقاعدة معرفة محلية، وOllama عند تشغيله.
- مسار بحث ويب اختياري عبر Tavily أو Brave مع إرجاع روابط المصادر، بالإضافة إلى استعلام مباشر عن أصول صناعية منشورة عبر Climate TRACE API (نسخة تجريبية).
- استيراد سجلات المنشآت من CSV مع إبقائها غير متحققة لحين تأكيدها.
- تم إيقاف إدخال المصانع والإعلانات التجريبية افتراضياً حتى لا تظهر كأنها بيانات سوق حقيقية.

## قبل فتح التسجيل العام

1. **التحقق من المنشآت:** تفعيل تأكيد البريد والهاتف، مراجعة المستندات، وتحديد صلاحيات ممثل المنشأة. حالة `is_verified` لا تُمنح تلقائياً.
2. **خصوصية وأمن:** سياسة خصوصية وشروط استخدام واتفاقية مشاركة بيانات، سياسة حذف واحتفاظ، نسخ احتياطية، TLS، إدارة أسرار، فحص ملفات مرفوعة، وسجلات تدقيق.
3. **حماية API:** تحديد معدلات الطلبات، حماية محاولات تسجيل الدخول، مراجعة الصلاحيات على كل سجل، واختبار اختراق مستقل قبل استقبال بيانات تجارية حساسة.
4. **التعاقد والمدفوعات:** مراجعة قانونية للعقود، آلية نزاعات، شروط التسليم والوزن والفحص، بوابة دفع مرخصة إذا كان تحصيل الأموال داخل المنصة مطلوباً. النسخة الحالية لا تحصّل أموالاً؛ أوامر التوريد تبقى Pending ولا تسجل دفعاً أو شحناً مؤكداً.
5. **البيانات الصناعية:** لا تنشر مصنعاً كمورد أو مشترٍ إلا بعد تأكيده. سجلات الدليل العام ليست دليلاً على توفر مخلفات أو طلب خامات.
6. **البيئة وESG:** توثيق معامل كل مادة ومصدره وسنة الأساس وحدود النظام والسيناريو المرجعي، ومراجعة خبير. لا تسوّق النتائج كشهادة معتمدة حالياً.
7. **التشغيل:** استضافة PostgreSQL، تخزين دائم للملفات، نسخ احتياطية مجربة، مراقبة أخطاء وتنبيهات، نطاق وHTTPS، واختبارات ضغط واستعادة.
8. **الذكاء الاصطناعي:** لا تعتمد على موديل محلي على جهاز المطور لخدمة الجمهور. يمكن تشغيل Ollama داخلياً على VPS عبر Docker Compose profile `ai` أو ربط inference بمزود مستضاف. لا تعرض منفذ Ollama للعامة. أضف حدود استخدام وتكلفة ومراقبة.

## مصادر بيانات منشآت ومصانع

- مصر: [Made in Egypt Gate](https://madeinegyptgate.com/about/?lang=en) دليل صناعي ومنصة B2B؛ احصل على موافقة/شراكة قبل النسخ الجماعي.
- مصر: [المنصة الصناعية الرقمية الرسمية](https://mind.gov.eg:8041/) موجهة للمنشآت المسجلة؛ لا تفترض وجود API عام أو حق scraping.
- عالمي: [Climate TRACE API](https://api.climatetrace.org/v7/docs/index.html) يتيح استعلامات عن أصول/مصادر انبعاثات صناعية حسب القطاع والبلد؛ سجلاته ليست دليل مشتري/مورد ولا توفر بالضرورة بيانات تواصل، والواجهة في إصدار تجريبي.
- عالمي: [IndustryAtlas](https://inzonex.co.uk/industryatlas/about) يصف سجلاً لـ 29,681 منشأة في 165 دولة ويذكر أن مجموعات بياناته المفتوحة CC BY 4.0؛ تحقق من ترخيص كل ملف ومصدره قبل الاستخدام.
- الولايات المتحدة فقط: [M-FIND على Zenodo](https://zenodo.org/records/21827821) يضم 340,229 سجلاً للمنشآت الصناعية الأمريكية، ولا يمثل دليلاً للمصانع المصرية.
- تدفقات ومواد صناعية: [IEDC](https://www.database.industrialecology.uni-freiburg.de/) يضم أكثر من 460 مجموعة بيانات ونحو 3.7 مليون نقطة بيانات؛ راجع ترخيص واستشهاد كل مجموعة على حدة.

## نشر عام

ملف `render.yaml` يجهز خدمة ويب وقاعدة PostgreSQL. ما زال مطلوباً منك إنشاء حساب الاستضافة، ربط المستودع، تعيين الدومين، وضبط `CORS_ORIGINS` ومفاتيح البحث وأي خادم AI. لا يمكن إتمام نشر عام أو إنشاء حسابات الاستضافة أو شراء نطاق من داخل ملفات المشروع وحدها.
